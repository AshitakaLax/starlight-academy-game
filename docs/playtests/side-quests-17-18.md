# Side quests 17–18: Chapter 9 playtest notes

## The Chimera's Operation Blueprint

**Type:** Mastery extension  
**Activity:** Compare four operation plans and select the sequence that follows a curated multi-step story.

Foundation and Core questions use two operations; Stretch questions include three operations. Every plan is distinct, exactly one matches the curated story, and the correct option is shuffled among A–D. The task focuses on translating event order into an operation plan rather than calculating the chapter's final answer again.

**Reward:** Chimera's Blueprint Compass — 85 Star Gems and 6 Starlight Sparkles, claimable once.

## The Workshop Supply Planner

**Type:** Practical application  
**Activity:** Solve a new supply problem by carrying intermediate results forward.

Foundation uses addition followed by subtraction. Core multiplies the number of bundles per crate by the crate count, then subtracts reserved bundles. Stretch adds an equal-sharing division step and constructs values so the remainder divides evenly among teams.

**Reward:** Chimera's Supply Satchel — 90 Star Gems and 6 Starlight Sparkles, claimable once.

## Regression coverage

Automated tests cover all three tiers, deterministic seeded output, curated operation-order correctness, distinct answer plans, generated supply arithmetic, hint stages, checkpoint/resume, replay, and one-time rewards.
